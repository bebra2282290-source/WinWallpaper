# WinWallpaper

Лёгкая программа для Windows, которая ставит видео обоями рабочего стола: ролик
играет за значками, как обычная картинка. Главная цель — почти не тратить
ресурсы компьютера.

*English summary: a tiny native (C++/Win32) video wallpaper for Windows 10/11.
GPU decoding through Media Foundation, auto-pause in fullscreen apps, when the
desktop is covered, on battery and when the screen is locked or off.*

## Возможности

- Любое видео, которое умеет Windows: MP4 (H.264, H.265/HEVC), MKV, WebM (VP9, AV1), MOV, WMV, AVI.
- Видео за значками рабочего стола, в Windows 10 и Windows 11 (включая 24H2 и новее).
- Несколько мониторов: видео растягивается на каждый экран, а декодируется один раз на все.
- Масштаб: «заполнить экран» (с обрезкой краёв), «вписать целиком» (с чёрными полями), «растянуть».
- Звук по желанию (по умолчанию выключен).
- Значок в трее, автозапуск вместе с Windows.
- Один файл `.exe` без установки, без .NET, браузера или Electron.

## Почему программа почти не нагружает компьютер

| Что сделано | Что это даёт |
|---|---|
| Видео декодирует видеокарта (DXVA через Media Foundation), кадр не покидает GPU | Процессор почти не участвует |
| Один декодер на все мониторы | Второй экран не удваивает нагрузку |
| Кадр выводится, только когда он действительно новый; между кадрами поток спит до обновления экрана | Нет пустой работы |
| **Автопауза**, когда открыта игра или любое полноэкранное приложение | Игры получают все ресурсы |
| **Автопауза**, когда рабочий стол целиком закрыт окнами; монитор, закрытый окнами, перестаёт перерисовываться отдельно | Обои не работают, когда их не видно |
| **Автопауза** при работе от батареи и в режиме экономии энергии | Ноутбук живёт дольше |
| **Автопауза** при блокировке компьютера, смене пользователя и выключенном экране | |
| На паузе — 0% процессора и видеокарты: поток просто спит | |
| Без звука аудиодорожка вообще не декодируется | |
| Пониженный приоритет процесса и «режим эффективности» Windows 11 | Программа всегда уступает вашим приложениям |
| Ограничение частоты кадров (30 или 15 кадров/с) по желанию | Ещё меньше работы для видеокарты |
| На ноутбуках с двумя видеокартами используется та, к которой подключён экран (обычно встроенная, экономичная) | Меньше расход батареи |

## Установка

1. Скачайте `WinWallpaper-x64.exe` (для ARM-ноутбуков — `WinWallpaper-ARM64.exe`)
   со страницы **Releases** репозитория или из раздела **Actions** → последний запуск
   «Build» → **Artifacts**.
2. Положите файл в любую папку (например, `C:\Programs\WinWallpaper`) и запустите.
3. Файл не подписан цифровой подписью, поэтому Windows SmartScreen может показать
   предупреждение: нажмите «Подробнее» → «Выполнить в любом случае».

При первом запуске программа сама предложит выбрать видео.

## Как пользоваться

Всё управление — через значок в трее (возле часов). Нажмите на него левой или
правой кнопкой мыши:

| Пункт меню | Что делает |
|---|---|
| Выбрать видео… | Открывает выбор файла |
| Пауза | Останавливает видео вручную |
| Масштаб | Заполнить экран / вписать целиком / растянуть |
| Звук | Выключен, 10–100% |
| Частота кадров | Как в видео / не больше 30 / не больше 15 кадров/с |
| Экономия ресурсов | Включение и выключение автопауз (все включены по умолчанию) |
| Запускать вместе с Windows | Автозапуск при входе в систему |
| Убрать видеообои | Возвращает обычные обои Windows |
| Выход | Закрывает программу, обычные обои возвращаются |

Подсказка у значка показывает, играет ли видео, а если стоит пауза — почему.

Ещё можно перетащить видеофайл на `WinWallpaper.exe` — он станет обоями.

## Советы для минимальной нагрузки

- Лучше всего подходит **MP4 с кодеком H.264** в разрешении не выше вашего экрана
  и с частотой 24–30 кадров/с. Его аппаратно декодирует любая видеокарта последних 10+ лет.
- 4K-видео с 60 кадрами/с тоже работает, но нагружает видеокарту заметно сильнее.
- Пережать видео под обои можно бесплатной программой [ffmpeg](https://ffmpeg.org/):

  ```
  ffmpeg -i исходное.mp4 -vf scale=1920:-2 -r 30 -c:v libx264 -crf 23 -preset slow -an обои.mp4
  ```

## Форматы и кодеки

Программа использует встроенный в Windows проигрыватель (Media Foundation),
поэтому поддерживает то же, что и приложение «Кино и ТВ»/«Медиаплеер»:

- **H.264, MPEG-4, WMV** — работают сразу.
- **H.265/HEVC** — нужно расширение «Расширения для видео HEVC» из Microsoft Store
  (на многих компьютерах уже установлено).
- **VP9** и **AV1** — расширения «VP9 Video Extensions» и «AV1 Video Extension» из Microsoft Store.
- В редакциях **Windows N** нужно установить «Пакет компонентов мультимедиа» (Media Feature Pack).

## Настройки

Настройки хранятся в `%APPDATA%\WinWallpaper\settings.ini`. Если рядом с
`WinWallpaper.exe` создать пустой файл `WinWallpaper.ini`, программа будет
хранить настройки в нём (переносной режим, например для флешки).

Несколько параметров есть только в файле — на случай проблем:

| Параметр | Значения | Зачем |
|---|---|---|
| `PresentMode` | `0` — авто (по умолчанию, сейчас это flip), `1` — flip, `2` — blt, `3` — DirectComposition | Способ вывода кадров на экран. Попробуйте `3`, если видео не видно |
| `LayeredWindow` | `0` — авто (по умолчанию), `1` — да, `2` — нет | Тип окна с видео. В Windows 11 24H2 и новее «авто» означает «да» |
| `EfficiencyMode` | `1` — да (по умолчанию), `0` — нет | Пониженный приоритет и «режим эффективности». Выключите, если видео подтормаживает на очень слабом процессоре |
| `Log` | `0` — нет (по умолчанию), `1` — да | Писать журнал `WinWallpaper.log` рядом с файлом настроек. Пригодится, если что-то не работает |

Меняйте файл, когда программа закрыта.

## Командная строка

```
WinWallpaper.exe "D:\Видео\обои.mp4"   поставить видео (и запустить программу, если она не запущена)
WinWallpaper.exe --exit                 закрыть запущенную программу
WinWallpaper.exe --log                  запустить с журналом WinWallpaper.log
```

Повторный запуск `WinWallpaper.exe` без параметров открывает выбор видео у уже
запущенной копии.

## Если что-то не так

- **Видео стоит на месте.** Скорее всего, сработала автопауза — наведите мышь на
  значок в трее, там написана причина. Ненужные паузы выключаются в меню «Экономия ресурсов».
- **«Не удалось воспроизвести видео».** Windows не умеет этот кодек — поставьте
  расширение из раздела «Форматы и кодеки» или пережмите видео в MP4 H.264.
- **Видео не видно за значками.** Перезапустите программу. Если не помогло,
  попробуйте `PresentMode=3` (а затем `LayeredWindow=2`) в файле настроек.
  Запуск с `--log` запишет журнал, по которому видно, что пошло не так.

## Удаление

Снимите галочку «Запускать вместе с Windows», выберите «Выход» и удалите
`WinWallpaper.exe` и папку `%APPDATA%\WinWallpaper`.

## Сборка из исходников

Нужны Visual Studio 2022 (компонент «Разработка классических приложений на C++»)
и CMake 3.20+:

```
cmake -S . -B build -A x64
cmake --build build --config Release
```

Готовый файл: `build\Release\WinWallpaper.exe`. Для ARM64 замените `-A x64` на `-A ARM64`.
GitHub Actions собирает обе версии при каждом изменении, а при создании тега
`v*` (например, `v1.0.0`) публикует их на странице Releases.

## Как это устроено

| Файл | Назначение |
|---|---|
| `src/main.cpp` | Точка входа, единственный экземпляр, разбор командной строки |
| `src/App.cpp` | Значок в трее, меню, реакция на системные события, решение «играть или пауза» |
| `src/Desktop.cpp` | Встраивание окна за значки рабочего стола (классическая схема и схема Windows 11 24H2+) |
| `src/VideoRenderer.cpp` | Direct3D 11 + Media Foundation Media Engine: аппаратное декодирование и вывод кадров |
| `src/Activity.cpp` | Проверки: полноэкранное приложение, закрыт ли рабочий стол окнами, питание от батареи |
| `src/Settings.cpp` | Настройки и автозапуск |
| `src/Strings.cpp` | Тексты интерфейса на русском и английском |

## Ограничения

- Одно видео сразу на всех мониторах.
- Только локальные файлы (без ссылок на YouTube и т. п.).
- Видео всегда зациклено.
